# University Workshop Java Programming Repository

## Overview

This repository contains materials and exercises for the University Workshop on Java Programming. The workshop is conducted weekly and covers various Java programming concepts. Below is a schedule of activities for the entire workshop.

## Week 1-12

### Week 1
- **Lecture:** Intro, Java conventions, Java tools
- **Workshop "See One":** Circle Class (CI4105 revision)
- **Workshop "Do One":** Circle Encapsulation
- **Self-Study:** Static Java Programming (CI4105 revision)

### Week 2
- **Lecture:** Classes, Constructors, and Encapsulation
- **Workshop "See One":** Citizen OO
- **Workshop "Do One":** Bank Account OO
- **Self-Study:** Bank Account 2 - OO

### Week 3
- **Lecture:** Java Classes and Inheritance part 1
- **Workshop "See One":** Customer Construction OO
- **Workshop "Do One":** Building with Rooms
- **Self-Study:** Static-on-the-line

### Week 4
- **Lecture:** Java Classes and Inheritance part 2
- **Workshop "See One":** University OO
- **Workshop "Do One":** Refactor Sock Drawer
- **Self-Study:** OO Modelling

### Week 5
- **Lecture:** Java APIs: Introducing the Java Collection Framework
- **Workshop:** Gateway Test 1 -- some FAQs on the "gateway" principle

### Week 6
- **Break/Half Term/Reading Week/EAW**

### Week 7
- **Lecture:** Java APIs: Using the Java Collection Framework part 1
- **Workshop "See One":** Loop-less pair
- **Workshop "Do One":** List-to-Array, List-to-Set
- **Self-Study:** Document / Line / Word & bonus recording

### Week 8
- **Lecture:** Java APIs: Using the Java Collection Framework part 2
- **Workshop "See One":** Unique elements
- **Workshop "Do One":** Map Implementation
- **Self-Study:** Map Keys-to-Array, Map Values-to-Array

### Week 9
- **Lecture:** Java Equality and Comparisons
- **Workshop "See One":** Media Item - Equality
- **Workshop "Do One":** Media Item - Hash code
- **Self-Study:** Unique elements - Streams

### Week 10
- **Lecture:** Java APIs: Introducing Exceptions
- **Workshop "See One":** Exception to the Rule
- **Workshop "Do One":** Catch exception
- **Self-Study:** Tic Tac Toe with bonus recording

### Week 11
- **Lecture:** Java APIs: Using Java I/O
- **Workshop "See One":** Read CSV File
- **Workshop "Do One":** Read File, Write File

### Week 12
- **Workshop:** Gateway Test 2 prep -- AMA
- **Self-Study:** KUGitlab Portfolio2023 Personal Sub-groups
